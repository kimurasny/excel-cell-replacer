# excel-cell-replacer（Excel文字列置換・複製CLIツール）

Excelファイル（`.xlsx` / `.xlsm`）の指定セルに含まれる文字列を、CSVファイルで定義した置換ルールに従って置換し、
**別名のExcelファイルとして複製**するコマンドラインツールです。元のExcelファイルは変更しません。

- 複数の置換ルールをCSVで管理し、1回の実行でまとめて置換できます。
- すべてのルールを事前に検証し、1件でもエラーがあれば出力ファイルを作成しません。
- 置換対象以外のセル・書式・数式・画像・マクロなどは、openpyxl で可能な範囲で維持します（[制約](#excelファイルの保持に関する制約)を参照）。

## 動作環境

| 項目 | 内容 |
| --- | --- |
| Python | 3.9 以上（3.9 / 3.12 で動作確認） |
| OS | Windows / macOS / Linux |
| 依存ライブラリ | `openpyxl` 3.1 系、`Pillow`（画像の保持に必要） |
| Excel形式 | `.xlsx`、`.xlsm` |
| CSV文字コード | UTF-8（BOM付きも可） |

`Pillow` は画像を保持するためだけに使用します。未インストールの場合、openpyxl は画像を読み込まないため、出力ファイルから画像が削除されます。

## インストール方法

```bash
git clone https://github.com/kimurasny/excel-cell-replacer.git
cd excel-cell-replacer

# 仮想環境の作成（任意）
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows（PowerShell）
.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

Windows で `python` コマンドが見つからない場合は `py` に読み替えてください。

## コマンド実行方法

```bash
python excel_replace.py --input template.xlsx --csv replace.csv [--output 出力ファイル]
```

| 引数 | 必須 | 説明 |
| --- | --- | --- |
| `--input` | 必須 | 複製元Excelファイル（`.xlsx` / `.xlsm`） |
| `--csv` | 必須 | 置換定義CSVファイル |
| `--output` | 任意 | 出力Excelファイルのパス |

### 出力ファイル

- `--output` を省略した場合、**CSVファイルと同じディレクトリ**に「**CSVのベース名＋入力Excelの拡張子**」で出力します。
  - 例: `--input template.xlsx --csv data/customer_A.csv` → `data/customer_A.xlsx`
  - 例: `--input template.xlsm --csv customer_A.csv` → `customer_A.xlsm`（マクロ有効ブックとして出力）
- `--output` を指定する場合も、拡張子は入力Excelと同じにしてください（異なる場合はエラー）。
- 出力先に同名のファイルが既に存在する場合は、**上書きせずエラー**とします。
- 出力先ディレクトリは自動作成しません。

### 終了コード

| コード | 意味 |
| --- | --- |
| `0` | 正常終了 |
| `1` | 置換ルール・入力内容のエラー（引数不正、ファイル不存在、CSV不正、シート・文字列の不存在、出力ファイルの重複など） |
| `2` | ファイルの読み込み・保存などの実行エラー（Excelファイルの破損、書き込み失敗など） |

## CSVの記述方法

1行目はヘッダー行で、以下の4列を定義します（列の順序は任意、列名は小文字の英字）。

| 列名 | 説明 |
| --- | --- |
| `sheet` | 対象シート名（完全一致） |
| `cell` | 対象セル番地（A1形式。例: `B2`。小文字の `b2` も可） |
| `before` | 置換前文字列（空文字不可） |
| `after` | 置換後文字列（空文字可。文字列の削除に使用） |

```csv
sheet,cell,before,after
表紙,B2,株式会社AAA,株式会社BBB
表紙,B3,2025年度,2026年度
設定,C5,開発環境,本番環境
設定,D10,旧システム,新システム
```

サンプル: [examples/replace.csv](examples/replace.csv)

### 処理ルール

- 1行を1つの置換ルールとして扱い、CSVの記載順に置換します。
- 同じシート・セルに複数のルールを指定できます。2件目以降は、**前のルールで置換した結果**に対して検証・置換します。
- 置換はセル内文字列の**部分一致**で行い、同じ文字列が複数あれば**すべて**置換します。
- 大文字・小文字は区別します。
- 前後の空白は自動削除しません（`" 御中"` のように空白を含めて指定できます）。
- カンマ・改行・ダブルクォートを含む値は、CSVの規則どおり `"` で囲んでください（`"` 自体は `""` と記述）。
- 空行（すべての列が空の行）は無視します。
- 置換対象は文字列セルのみです。数値・日付・真偽値・空セル・数式セル・エラー値セル・結合セルの左上以外のセルはエラーになります。
- 置換後の文字列が `=` で始まっていても、数式ではなく文字列として保存します。
- セル内の一部に書式（太字・色など）が設定されたリッチテキストは、置換前文字列が1つの書式範囲内に収まる場合は書式を維持して置換します。
  書式範囲をまたぐ場合は、そのセルのみプレーンな文字列として置換します（セル全体の書式は維持されます）。

## 実行例

```console
$ python excel_replace.py --input template.xlsx --csv customer_A.csv
Excel文字列置換処理を開始します。

入力Excel : template.xlsx
置換CSV   : customer_A.csv
出力Excel : customer_A.xlsx

置換成功:
  [2行目] 表紙!B2
  [3行目] 表紙!B3
  [4行目] 設定!C5
  [5行目] 設定!D10

置換件数: 4
処理結果: SUCCESS
```

出力先を指定する場合:

```bash
python excel_replace.py --input template.xlsm --csv customer_A.csv --output out/見積書_A社.xlsm
```

## エラー時の動作

- 置換前に**すべてのルールを検証**し、1件でもエラーがあれば**出力ファイルを作成しません**。
- エラーは可能な限りまとめて表示します（CSVの行番号・シート名・セル番地・エラー内容を含む）。エラーは標準エラー出力に出力されます。
- 保存は一時ファイルに書き込んでから出力先へ移動するため、保存に失敗しても不完全な出力ファイルは残りません。
- 元のExcelファイルは読み込むだけで、変更しません（`--output` に入力ファイルを指定しても「既に存在する」エラーになります）。

```console
$ python excel_replace.py --input template.xlsx --csv customer_B.csv
Excel文字列置換処理を開始します。

入力Excel : template.xlsx
置換CSV   : customer_B.csv
出力Excel : customer_B.xlsx

ERROR: 置換処理に失敗しました。

[3行目] シート「設定」が存在しません。
[5行目] シート「表紙」セル「B10」に置換前文字列「株式会社AAA」が存在しません。

エラー件数: 2
出力ファイルは作成されませんでした。
```

主なエラー:

| エラー | 終了コード |
| --- | --- |
| 入力Excelファイル・CSVファイルが存在しない | 1 |
| Excelファイルの拡張子が対象外（`.xlsx` / `.xlsm` 以外） | 1 |
| CSVのヘッダーが不正、列数が不正、UTF-8で読み込めない、置換ルールが存在しない | 1 |
| 必須項目（`sheet` / `cell` / `before`）が未設定 | 1 |
| セル番地が不正（A1形式以外、範囲指定、`$B$2` など） | 1 |
| 指定シートが存在しない | 1 |
| 対象セルが文字列型ではない（数値・数式・空セルなど） | 1 |
| 対象セルに置換前文字列が存在しない | 1 |
| 出力先ファイルが既に存在する、出力先ディレクトリが存在しない | 1 |
| Excelファイルの読み込み・保存に失敗した | 2 |

## Excelファイルの保持に関する制約

本ツールは openpyxl でブック全体を読み込み、置換後に**ブック全体を書き出し直します**。
そのため、openpyxl が対応していない要素は出力ファイルで失われます。
以下は openpyxl 3.1.5 のソースコードの確認と、LibreOffice で作成した図形・フォームコントロール・グラフ・外部参照を含むファイルでの実測に基づきます。

### 保持される要素

- シート構成・シート名・シートの順序、非表示シート
- セルの値・書式（フォント・背景色・罫線・配置・表示形式）、条件付き書式（標準形式のもの）、入力規則（標準形式のもの）
- セル結合、行の高さ・列の幅、ウィンドウ枠の固定
- 数式（数式の文字列は維持。ただし下記「数式の計算結果」を参照）、名前の定義
- 印刷設定（用紙サイズ・向き・余白・印刷範囲・ヘッダー/フッター）
- 画像（PNG / JPEG など。`Pillow` が必要）
- グラフ（ただし細かな書式が変わる場合があります）
- コメント（メモ）の内容
- テーブル（リスト）、ピボットテーブル
- 外部ブックへのリンク（外部参照）※ `keep_links=True`（openpyxl の既定）で保持
- マクロ（`.xlsm` の VBA プロジェクト `xl/vbaProject.bin`）※ `keep_vba=True` で読み込み、そのまま複製

### 保持されない・制約のある要素

| 要素 | 内容 |
| --- | --- |
| 図形・テキストボックス・SmartArt | **失われます**（実測でも出力から削除されることを確認）。警告も出ません。 |
| フォームコントロール（ボタン等） | `.xlsx` では**失われます**。`.xlsm` では関連ファイル（VML・`ctrlProps`）は複製されますが、シート側の `<controls>` 定義が失われるため、Excel上で表示・動作しない可能性が高いです。 |
| ActiveXコントロール | `.xlsx` では失われます。`.xlsm` では `xl/activeX` 配下のファイルは複製されますが、シート側の参照が失われるため、利用できない可能性が高いです（ActiveX を含む実ファイルでの検証は未実施）。 |
| マクロ関連 | VBA プロジェクトは保持されますが、VBA のデジタル署名やリボンのカスタマイズ（`customUI`）は参照情報が書き出されないため、失われる可能性が高いです（未検証）。マクロのソースを openpyxl で編集・実行することはできません。 |
| シートの拡張情報（`extLst`） | スパークライン、スライサー、タイムライン、Excel 2010 以降の形式の条件付き書式（データバーの拡張設定など）・入力規則（別シート参照など）は失われます。 |
| 数式の計算結果 | openpyxl は数式の計算済みの値（キャッシュ）を保存しません。Excel で開くと再計算されますが、Excel 以外のビューアーでは計算結果が表示されない場合があります。 |
| 外部リンク | リンク定義は保持されますが、リンク先の値は Excel で開いた際に更新が必要になる場合があります。 |
| コメント | 内容は保持されますが、コメント枠のサイズ・位置・書式は既定値に戻ります。 |
| 画像 | `Pillow` で読み込めない形式（環境により EMF / WMF など）は失われます。 |
| リッチテキスト | 置換前文字列が書式範囲をまたぐセルは、そのセルのみ部分書式が失われます（上記「処理ルール」参照）。 |

入力Excelに図形・コントロール・`extLst`・`customUI` が含まれる場合、処理成功時に以下のような警告を表示します（処理は継続します）。

```text
警告: openpyxlの制約により、以下の要素は出力Excelで失われている可能性があります。
  - 図形・テキストボックス
  - フォームコントロール・ActiveXコントロール
```

図形やコントロールを含むブックを扱う場合は、出力結果を Excel で確認するか、
図形を含まないテンプレートを用意することを推奨します。

## テスト実行方法

```bash
pip install -r requirements-dev.txt
python -m pytest
```

テストは `tests/test_excel_replace.py` にあり、テスト用のExcel（`.xlsx` / `.xlsm`）は実行時に一時ディレクトリへ自動生成します。
